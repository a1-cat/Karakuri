# Karakuri (からくり) プラグイン

Create Modにインスパイアされた、Minecraft純正（バニラ）サーバー向けの「動く建築」プラグインです。
Display Entity (`BlockDisplay`) のクライアント側補間（Interpolation）機能を活用し、パケット負荷を最小限に抑えながら60fps級の超スムーズなアニメーションを実現します。

---

## 2つの専用ツールと使い方

### 1. 『からくりのレンチ（銅のクワ）』
入手コマンド: `/kk wrench`
* **通常ブロックを右クリック**: からくりに瞬時変換！
* **からくりを右クリック**: **メイン設定盤 GUI** を開く！
  * 🚪 **ドアモード**: 中心を軸に90度スムーズ開閉（素手クリック開閉＆3秒後自動クローズ）
  * 🔄 **風車モード (Z軸)** / 🎡 **水車モード (X軸)** / 🎠 **回転台 (Y軸)**
  * 🔁 **回転方向切替**: 時計回り $\leftrightarrow$ 反時計回りを反転
  * ↕️ **直線運動設定盤を開く**
  * 🧩 **プログラム編集盤を開く**
  * 🗑 **撤去して通常ブロックに戻す**

---

### 2. 『からくりのピストンロッド（避雷針）』
入手コマンド: `/kk rod`（または `/kk piston`）
エレベーターやスライドドアなどの直線運動に特化した専用ツールです。
* **通常ブロックを右クリック**: 直線運動からくりに瞬時変換！
* **からくりを右クリック**: **直線運動設定盤 GUI** を開く！
  * **軸選択**: ↔ X軸（東西スライド） / ↕ Y軸（上下エレベーター） / ↔ Z軸（南北スライド）
  * **距離調整**: ➕ 距離+1 / ➖ 距離-1（1〜20ブロックまで自由に設定）
  * **動作モード切替**:
    * 🕹️ **手動トグルモード**: 素手で**左クリック**（または右クリック）すると前進/後退！
    * 🔁 **自動往復モード**: 終点と始点を自動でリピート往復！

---

### 3. 自由設計『プログラム編集盤 GUI』
メインGUIの「🧩 プログラムモード」から開きます。
* 上段の4つのスロット（ステップ1〜4）をクリックするだけで、以下のアクションを自由に組み替え可能：
  * 🔄 Y軸回転 (+90° 時計回り) / (-90° 反時計回り)
  * ⬆️ 上昇 (+3ブロック) / ⬇️ 下降 (-3ブロック)
  * ➡️ X軸移動 (+3ブロック) / ⬅️ X軸戻る (-3ブロック)
  * ➡️ Z軸移動 (+3ブロック) / ⬅️ Z軸戻る (-3ブロック)
  * ⏱️ 1秒待機 (20ticks)
  * ⏹️ なし (スキップ)
* 再生方式: [🔁 自動永久ループ] $\leftrightarrow$ [🕹️ クリック手動進行]
* 「▶ プログラムを適用して実行！」で即座に反映！

## コマンド一覧 (`/karakuri` または `/kk`)

| コマンド | 説明 | 例 |
|---|---|---|
| `/kk wrench` | **『からくりのレンチ（銅のクワ）』を入手** | `/kk wrench` |
| `/kk rod` | **『からくりのピストンロッド（避雷針）』を入手** | `/kk rod` |
| `/kk reload` | **サーバーを閉じずにプラグインをホットリロード（JAR差し替え反映）** | `/kk reload` |
| `/kk revert` (または `/kk undo`) | **視線先のからくりを通常ブロックに戻す** | `/kk revert` |
| `/kk clear` | **ワールド内の全からくりを完全消去** | `/kk clear` |
| `/kk stop` / `/kk list` | 動作停止 / 一覧確認 | `/kk stop` |
